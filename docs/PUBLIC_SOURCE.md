# Public source

This repository contains the application's source code and historical schema migrations.

- Production data-fix scripts are private and excluded from all published revisions.
- Administrator contact details and Git author email addresses have been anonymized.
- Historical player/profile identifiers in migrations and tests use fictitious values. They must not be used to modify production accounts.
- `admin@example.invalid` is a placeholder. Configure the administrator identity for your own deployment; never rely on this placeholder for a production installation.
- Supply environment values through your private deployment configuration. Never commit credentials, private keys, production data or database backups.

The original, unsanitized history is retained separately as a private backup. These changes do not modify the hosted application or production database.
